Rippa Record · First-run setup

Set up your recording rig

Choose the playback app, audio route, and Reason project settings for this Mac. You can change these preferences later from Rippa’s menu-bar icon.

1. Choose your playback app

Rippa can pause the selected player while it arms Reason. The actual recording follows the system audio route you choose next.

This preference does not isolate one application’s audio. Rippa records the signal routed through the selected macOS output and the configured Reason input.

2. Choose the audio route

Pick the virtual recording input and the macOS output that feeds it. Device suggestions come from this Mac; you can still type a device name if needed.

3. Choose your Reason project and track

Rippa automates Reason for recording and export. The selected sequencer track is located by its visible name, not a saved screen coordinate.

4. Review your setup

These settings are saved to this Mac’s Rippa preferences and are used on the next recording.

Rippa will still ask macOS for Accessibility and Automation permissions when needed. Device or project changes can be made later from Preferences & device setup.

Close this window to finish setup later. Rippa will not start recording until you choose Start Recording.
